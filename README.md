## About Open Motion

**Open Motion** is a free and open-source browser-based animation and video
editing project designed with a strong focus on mobile workflows.

The project currently focuses on keyframe animation, vector editing,
layer-based editing, 3D transforms, timeline controls, and experimental
high-performance rendering.

More advanced motion graphics and visual effects features are still under
active development.

---

## Features

### ⌨️ Keyframe Animation

Animate layer properties using timeline-based keyframes with interpolation
controls.

### 📈 Curve & Easing Editing

Fine-tune animation timing using easing controls and curve editing tools.

### ✒️ Vector Path Editing

Create and edit vector paths with anchors, Bézier handles, point insertion,
open and closed paths, and touch-oriented editing controls.

### 🧭 3D Transform Controls

Work with position and rotation in 3D space, including camera-oriented
transform workflows.

### 🧱 Layer-Based Editing

Build compositions using multiple editable layers with timeline controls,
visibility, ordering, and contextual property editing.

### 🎚️ Timeline Editing

Control layer timing, keyframes, playback position, duration, and animation
properties through the timeline interface.

### ⚡ Rendering & Playback

Open Motion includes experimental rendering and playback systems focused on
performance, GPU acceleration, export quality, and mobile hardware.

### 📱 Mobile-First Interface

The editor is designed around touch interaction while remaining usable on
desktop browsers.

### 🌐 Browser Based

Open Motion currently runs directly in a modern web browser without requiring
a traditional installation or build process.

### 📲 Progressive Web App

Open Motion includes PWA support and can be installed from supported browsers
for a more app-like experience.

### 🆓 Free & Open Source

Open Motion is released as open-source software under the MIT License.

## Future Native Architecture

Open Motion is currently developed as a web-based application. This makes it
faster to experiment with new ideas, test editor workflows, and iterate on
features while the project is still in an early stage.

In the future, there are plans to explore a native version of Open Motion,
including an Android application, once suitable native technologies are mature
enough for the project.

### Opus Framework

Open Motion may evaluate [Opus Framework](https://youtu.be/bB4_B7TCoMY?si=6yFhzkhmmRT1DMR5)
as one possible foundation for a future native version once it becomes publicly
available.


## Technology

The current prototype is primarily built with:

- HTML
- CSS
- JavaScript
- Canvas
- WebGL
- Browser media APIs
- Progressive Web App technologies

The current prototype intentionally remains largely self-contained while
the architecture continues to evolve.

---

## Browser Compatibility

Google Chrome is currently the recommended browser for testing Open Motion.

Because Open Motion uses modern browser APIs for rendering, media processing,
GPU acceleration, fullscreen behavior, and local project storage, some features
may behave differently or may not yet work in other browsers.

Mobile Chrome is currently one of the primary development targets.
